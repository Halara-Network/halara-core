# Halara Core (legacy)

Shared help, moderation broadcasts, proxy navigation, and the server-selector UI
for the legacy multi-jar Halara deployment.

Active development has moved to the private
[`Halara-Network/halara-network`](https://github.com/Halara-Network/halara-network)
repository, where this behavior is the `core` module of one configurable jar.
Keep this repository as a production rollback point during migration.
